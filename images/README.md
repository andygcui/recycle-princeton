# Item Images

Place PNG images of each item in this folder.

## Required Images

The game expects images with these exact filenames (all lowercase, spaces replaced with hyphens):

- `water-bottle.png`
- `milk-jug.png`
- `plastic-bag.png`
- `yogurt-cup.png`
- `styrofoam-cup.png`
- `soda-bottle.png`
- `detergent-bottle.png`
- `pvc-pipe.png`
- `mixed-plastic.png`

## Image Specifications

- **Format**: PNG (with transparency recommended)
- **Recommended size**: 200x200 pixels or larger
- **Aspect ratio**: Square or close to square works best
- **Background**: Transparent background recommended

## Where to Find Images

You can find free images from:
- Unsplash (unsplash.com)
- Pexels (pexels.com)
- Pixabay (pixabay.com)
- Or create your own illustrations

If images are not found, the game will use a fallback drawing with the item name and plastic code.
